The philosophy

Your backend already knows everything.
Stop teaching it twice.

Routes, permissions, URL helpers, form validation — it all lives in your backend. Reactolith treats server-rendered HTML as the composition layer for React. No parallel API. No duplicated state machine. No SPA tax.

①

HTML is the wire format

Return HTML from your existing controllers. Any tag with a hyphen — <my-button> — becomes a React component. The rest is plain DOM.

②

State survives navigation

A built-in router intercepts links and forms, fetches the next page, and patches only what changed. React state stays alive between pages.

③

Real-time, free

Pipe Mercure SSE, WebSockets or any stream into the same HTML pipeline. The page updates. The state you cared about doesn't blink.
