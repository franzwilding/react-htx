Installation

reactolith is published on npm. Install it alongside React and React DOM.

Install the package

npm install reactolith

Install peer dependencies

react and react-dom are peer dependencies — install them in your project too.

npm install react react-dom

Requirements

  • Node 18 or newer
  • React 19
  • A bundler that supports import.meta.glob (Vite, Rspack, …) is recommended for the loader workflow

Verify the install

import { App } from "reactolith"; console.log(typeof App); // "function"

Optional: HTTP/2 component preloading

Because reactolith resolves component tags lazily from the rendered HTML, the browser only discovers which chunks it needs after parsing the page. On HTTP/2 you can close that gap by telling a reverse proxy or CDN which components a page uses, and have it push (or 103 Early Hints) the corresponding JS chunks.

The convention reactolith adopts is a single response header that lists every custom-tag name found in the document:

X-Reactolith-Components: ui-button, ui-input, ui-label, ui-toaster

Implementing it on the backend is a few lines: walk the response body once it's rendered, collect any tag whose local name contains a hyphen, deduplicate, set the header. A reverse proxy then maps each name to its JS chunk and emits the corresponding Link /103 hints.

This is a deployment-time optimization — reactolith itself doesn't need it. It's documented here so backend bundles can agree on the same header name and format.
