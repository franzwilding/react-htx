Examples

The Reactolith repo ships a growing collection of runnable example apps under examples/. Each one is a complete, opinionated integration with a real backend framework — not a snippet isolated from its context. Clone the repo, run the example, and read the source side by side with this documentation.

Available examples

Symfony FormFlow multi-step form

A six-step application wizard built with Symfony's FormFlow component, fully themed with shadcn/ui, and hydrated by Reactolith. Demonstrates how to build a non-trivial backend-driven form without ever stepping outside the form theme:

  • Every field type Symfony ships: text, email, number, choice (single + multi), checkbox, radio, date/time, color, range, URL, password, file, collection, hidden, UUID, ULID.
  • Custom shadcn-style Select with search and keyboard navigation — rendered as <ui-select> with options passed via json-options='[…]' so React owns the list while Symfony owns the form data.
  • File uploads that survive going back and forth between steps, including delete and replace, with server-side persistence to a temp directory.
  • CollectionType with React-managed add/remove and a Symfony prototype that gets hydrated through ReactolithComponent on the fly.
  • Step indicator with click-to-go-back that reuses Symfony's PreviousFlowType button machinery.
  • Dark-mode toggle, scroll restoration, form-error display wired through useFormErrors.

Running an example

Each example has its own README, but the typical loop looks like:

git clone https://github.com/reactolith/reactolith.git cd reactolith/examples/symfony-multistep-form composer install npm install npm run dev # vite dev server with HMR symfony serve # or any PHP server pointing at public/

What these examples are not

Production-ready templates. They optimise for showing how a specific backend feature meets Reactolith on the client — file uploads live in sys_get_temp_dir(), sessions are in-memory, validation messages are hard-coded English. Treat them as recipes, not boilerplate to copy whole.
